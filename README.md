# Иван Вислов: портфолио

Практическая работа 1 по курсу «Веб-дизайн», СПбГУПТД. Вислов Иван, группа 5-МВ-5.

Сайт: https://vislovivan.github.io/web-01-portfolio/
Репозиторий: https://github.com/VislovIvan/web-01-portfolio

Одностраничное портфолио-резюме: о себе, опыт и образование, навыки, проекты с фильтром, контакты. Оформление в стиле раннего Macintosh, как на моём сайте 42jobs.dev.

## Как запустить

Открыть сайт по ссылке выше. Локально: скачать репозиторий и открыть `index.html` двойным щелчком, сборка и сервер не нужны.

## Функции

- Фильтр проектов по категориям «Продукты» и «Личные и учебные», кнопка «Все», активная категория выделена, в каждой кнопке счётчик.
- Поиск по проектам. Если ничего не нашлось, появляется сообщение и кнопка «Показать все».
- Светлая и тёмная тема: оформлены целиком, выбор сохраняется в localStorage. Если хранилище недоступно, переключатель всё равно работает. До первого выбора тема следует за настройкой системы.
- Мобильное меню: настоящая кнопка с `aria-expanded`, закрывается по пункту меню, по Escape и по нажатию вне меню. Фокус с клавиатуры виден.
- Подсветка текущего раздела в меню при прокрутке.
- Карточка «Веб-практики» ведёт на остальные работы курса: панель с API, игру, бронирование и итоговый сайт.
- Без JavaScript страница читается полностью, а меню на телефоне показано сразу.
- Нет горизонтальной прокрутки на ширине от 320 px.

Claude. Код получен по шагам в одном диалоге; после каждого шага сайт запускался и проверялся в браузере.

## Промпты, которые помогли

### 1. Основа сайта

```text
Создай современное портфолио-резюме на русском языке для студента
СПбГУПТД и iOS-разработчика. Имя Иван Вислов, навыки Swift, SwiftUI,
UIKit, TCA, Figma, проекты AiText, Lumen, ComponentsKit, RetroCut84,
42jobs и дипломный проект «Ровно». Блоки: первый экран, о себе,
образование, навыки, проекты, контакты. Оформление: ранний Macintosh,
как на моём сайте 42jobs.dev: светлый фон, рамка 2px, жёсткая тень,
шрифт Chicago в заголовках, синий акцент. Сделай Mobile First: сначала
телефон, потом компьютер. Используй только HTML, CSS и обычный
JavaScript, без React, npm и сборки. Пути должны быть относительными.
```

Результат: каркас страницы со всеми разделами и шестью карточками проектов. Тексты про опыт пришлось сверить с резюме и убрать лишнее.

### 2. Фильтрация

```text
Добавь фильтр карточек проектов по категориям «Продукты» и «Личные
и учебные» и кнопку «Все». При нажатии должны оставаться подходящие
карточки, активная категория должна выделяться. Если карточек нет,
покажи понятное сообщение. Реализуй на обычном JS, сохрани оформление.
```

Результат: фильтр на кнопках с `aria-pressed`. Чтобы сообщение о пустом результате можно было увидеть на деле, добавили поиск по проектам: при запросе без совпадений появляется подсказка и кнопка «Показать все».

### 3. Тема и мобильное меню

```text
Добавь переключатель светлой и тёмной темы. Обе темы должны быть
оформлены целиком: фон, текст, карточки, поля и кнопки. Сохраняй выбор
в localStorage, чтобы он оставался после обновления. Если сохранение
недоступно, переключатель всё равно работает. Затем добавь меню для
телефона: кнопка с aria-expanded, закрытие по пункту и по Escape,
видимый фокус для клавиатуры.
```

Результат: тема применяется ещё до отрисовки страницы, поэтому нет вспышки светлой темы. В тёмной теме рамки и тени светлые, как в инверсном режиме Mac. Меню дополнительно закрывается по нажатию вне его.

## Структура файлов

```text
index.html   разметка всех разделов
mac.css      общая база стиля: цвета, кнопки, поля, карточки, тёмная тема
style.css    раскладка портфолио
main.js      фильтр и поиск, тема, меню, подсветка раздела
fonts/       шрифт Chicago
img/         значки и снимки проектов в WebP
```

Шрифт Chicago (пиксельный, как в первых Macintosh) взят из проекта автора 42jobs.dev. Картинки проектов взяты с сайта автора vislovivan.github.io/projects.
